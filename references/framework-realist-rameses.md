# 现实主义综述与元叙事综述框架卡

依据：Pawson (2006)；RAMESES 出版标准（Wong et al., BMC Med 2013/2014）与质量标准（HS&DR 2014）。报告规范：RAMESES。哲学底座：批判现实主义。

## 现实主义综述（realist review）

核心问题不是"是否有效"，而是"**什么机制（M）在什么情境（C）下、对谁、产生什么结果（O）**"。产出物是 CMO 配置集合与精炼后的 programme theory。

### 循环流程（非线性，允许迭代）

1. **聚焦**：厘清为什么要做、目标用户、时间资源边界；形成初始 programme theory（从政策文本/已有综述/理论文献中提炼）
2. **检索**：目的导向而非穷尽导向——检索服务于理论精炼（theory-driven searching）。检索式围绕候选 C/M/O 概念展开；允许增量式补充检索（记录每轮动机，RAMESES 要求）
3. **筛选**：以"是否贡献 CMO 证据"为标准（相关性 + 严谨性双判据），而非 PICOS 适配
4. **提取**：逐篇提取 CMO 配置 + 上下文 + 来源学科；CMO 表是核心产出底稿
5. **综合精炼**：CMO 配置间比对、合并、回驳；修正 programme theory；必要时回到第 2 步
6. **报告**（RAMESES 19 条出版标准 + 8 项质量标准）：
   - 必须交代：理论框架来源、检索的迭代性与边界、CMO 配置的证据强度标注、programme theory 的最终形态
   - 流程图：RAMESES 允许非 PRISMA 形态，但须透明展示每轮检索与纳排

## 元叙事综述（meta-narrative review，附节）

适用：一个主题被多个研究传统用不同范式研究过，结论互相"打架"（如医学 vs 工程学 vs 管理学对同一技术的研究）。

- 步骤：识别研究传统 → 按传统分层检索与提取 → 绘制各传统内部的叙事演变 → 传统间对照（范式假设、质量标准、核心发现）
- 报告：RAMESES 元叙事标准（19 条）；突出"传统间冲突的范式根源"而非裁决谁对
